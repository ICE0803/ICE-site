## 注意力的直观理解

自注意力（Self-Attention）的核心思想是：让序列中的每个位置根据其他位置的信息来更新自己的表示。对于一个 token，它需要决定「应该关注序列中的哪些其他 token，以及关注多少」。

这个「关注多少」用注意力权重来表示，权重越大，说明当前位置越依赖对应的 token。

## 缩放点积注意力

给定输入矩阵 $X \in \mathbb{R}^{n \times d}$，我们通过三个可学习的权重矩阵得到查询、键和值：

$$
Q = X W_Q, \quad K = X W_K, \quad V = X W_V
$$

注意力计算分为三步：

1. 计算查询与键的点积，得到相似度分数；
2. 除以 $\sqrt{d_k}$ 缩放，防止点积过大导致 softmax 梯度消失；
3. 对分数做 softmax，再与值加权求和。

完整的公式为：

$$
\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right) V
$$

其中 $d_k$ 是键向量的维度。

## 最小实现

用 PyTorch 实现一个缩放点积注意力：

```python
import torch
import torch.nn.functional as F

def scaled_dot_product_attention(query, key, value, mask=None):
    d_k = query.size(-1)
    scores = torch.matmul(query, key.transpose(-2, -1)) / (d_k ** 0.5)
    if mask is not None:
        scores = scores.masked_fill(mask == 0, float("-inf"))
    attn = F.softmax(scores, dim=-1)
    return torch.matmul(attn, value)
```

## 多头注意力

单头注意力只能捕捉一种「关注模式」。多头注意力（Multi-Head Attention）将 $d_{model}$ 维的查询、键、值投影到 $h$ 个子空间，分别计算注意力后再拼接：

$$
\text{MultiHead}(Q, K, V) = \text{Concat}(\text{head}_1, \dots, \text{head}_h) W_O
$$

其中每个头为：

$$
\text{head}_i = \text{Attention}(Q W_i^Q, K W_i^K, V W_i^V)
$$

## 小结

自注意力通过「查询-键」匹配来决定信息聚合的权重，从而并行地建模序列中任意两个位置之间的依赖关系。理解这一机制，是理解 Transformer 及其后续变体的基础。

| 符号 | 含义 |
| --- | --- |
| $Q$ | 查询矩阵 |
| $K$ | 键矩阵 |
| $V$ | 值矩阵 |
| $d_k$ | 键向量维度 |
